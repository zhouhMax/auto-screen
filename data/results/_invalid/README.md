## invalid_20261110_close.json

- 日期/时段：2026-11-10 盘后（close），实际生成于北京时间 2026-11-10 **01:04** 与 **02:00** 两次运行
- 作废原因：GitHub `schedule` 触发被延迟 8~16 小时。`screen.yml` 三条 cron 为
  `15 1` / `35 6` / `35 7`（UTC，对应北京 09:15 / 14:35 / 15:35），但 11-09 的两条被
  推迟到 UTC 16:48 与 17:44（北京 11-10 00:48 / 01:44）。`auto_slot()` 只识别
  08:55-11:30 与 13:00-15:00，其余一律回落 `close`，`wait_for()` 又只 `sleep(900)`
  后继续，于是深夜跑出"盘后选股"并推送。
- 名单错误：该文件 3 只 F13（000017 深中华A 6.54 / 600540 新赛股份 4.96 /
  600641 先导基电 32.72）与 11-09 盘后推送**完全相同**，因为 01:04 快照取到的是
  11-09 收盘价，当日尚未开盘，无任何新信号。
- 处理：归档阻断 `sync_results.py` 回填（Excel 未写入，`选股池-TR.xlsx` 最后写入
  仍为 11-09 15:30，20261110 行数 0）；第二次 01:44 运行内容一致，`git diff` 为空，
  未产生新提交。
- 修复版本：`main.py` 增加交易时段闸门（`auto_slot()` 窗口外返回 `None`）与
  `wait_for()` 等待窗口（早于目标 >15 分钟 / 晚于 >30 分钟即 `ABORT` 中止），
  非交易时段的延迟触发将静默退出、不推送。
